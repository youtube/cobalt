# Cobalt 27 RC2 (Release Candidate 2)

The Cobalt team has published **Cobalt 27 RC2(Release Candidate 2)** including **Starboard API version 18** to the  [`27.lts`](https://github.com/youtube/cobalt/tree/27.lts) branch with tag [`27.lts.2`](https://github.com/youtube/cobalt/tree/27.lts.2) (`27.lts.2.1040572`).

* [cobalt/CHANGELOG.md](https://github.com/youtube/cobalt/blob/27.lts.2/cobalt/CHANGELOG.md)
* [starboard/CHANGELOG.md](https://github.com/youtube/cobalt/blob/27.lts.2/starboard/CHANGELOG.md)

Corresponding Evergreen binaries are available on [GitHub at the 27.lts.2 Release tag](https://github.com/youtube/cobalt/releases/tag/27.lts.2)

* NOTE: we are expecting to release on a periodic cadence (barring no blockers) leading up to LTS Stable for faster development

Cobalt Core can be updated via the Evergreen static channel (`27lts2`).

Please migrate and rebase your RC1 integrations to RC2 to get the latest fixes and improvements below.

The Cobalt team strongly encourages external contribution to fix issues and improvements.

* Please see the [Cobalt Contribution guidelines](https://developers.google.com/youtube/cobalt/docs/contributors) for additional details

Only the Starboard API is frozen. **This is ready for integration and we STRONGLY RECOMMEND you start integration of this Cobalt 27 LTS RC2 on your respective platforms early and report issues ASAP** so there is ample time to investigate and resolve any detected issues before Cobalt 27 LTS Stable Release later this year.

* For the latest changes, the code at tip in the [`27.lts`](https://github.com/youtube/cobalt/tree/27.lts) branch is always available, but is under development and may be unstable.

## Cobalt Changes

*NOTE: The below changes represent the delta between the RC1 and RC2 releases.*

See comprehensive list of changes in [cobalt/CHANGELOG.md](https://github.com/youtube/cobalt/blob/27.lts.2/cobalt/CHANGELOG.md) and baseline [release notes for Cobalt 27 RC](https://developers.google.com/youtube/cobalt/docs/releases/27.LTS.1) on cobalt.dev.

### Critical Bug Fixes/Improvements

* **Media & Video Decoding Fixes:** Resolved deadlocks and race conditions during MediaCodec surface destruction and teardown ([#11039](https://github.com/youtube/cobalt/pull/11039), [#10193](https://github.com/youtube/cobalt/pull/10193))
* **More Reliable Voice:** Improved microphone recording synchronization, reducing failed voice inputs and audio buffer capture dropouts ([#11396](https://github.com/youtube/cobalt/pull/11396))
* **Network & Storage Stability:** Resolved critical database, SSL security certificate, and network socket crashes to ensure secure local data storage, stable connections, and smoother recovery from temporary internet drops. ([#11413](https://github.com/youtube/cobalt/pull/11413), [#11417](https://github.com/youtube/cobalt/pull/11417), [#11062](https://github.com/youtube/cobalt/pull/11062), [#11061](https://github.com/youtube/cobalt/pull/11061), [#10871](https://github.com/youtube/cobalt/pull/10871))
* **Memory Stability & Crash Handlers:** Preserved critical crash details (siginfo signals) when Crashpad hands a failure back to the OS, resolved crashes linked to the HangWatcher system, and hardened against null pointer dereferences. ([#11321](https://github.com/youtube/cobalt/pull/11321), [#11264](https://github.com/youtube/cobalt/pull/11264))
* **Improved GPU & Graphics Throughput:** Increased GPU passthrough decoder texture unit limits from 64 to 96 (kMaxTextureUnits) to match RDK hardware driver limits ([#11362](https://github.com/youtube/cobalt/pull/11362))
* Fix white screen flash during preload/resume transitions ([#11062](https://github.com/youtube/cobalt/pull/11062), [#10871](https://github.com/youtube/cobalt/pull/10871))

### Android

* **Available AOSP Reference Port:** Official reference port now available for AOSP platforms (`aosp-arm`, `aosp-arm64`, `aosp-x86`). ([#11475](https://github.com/youtube/cobalt/pull/11475))

  * See documentation in [cobalt/tools/performance/memory/README.md](https://github.com/youtube/cobalt/blob/27.lts/cobalt/tools/performance/memory/README.md))
* Deeplink Testing Support in RDK Script ([#11450](https://github.com/youtube/cobalt/pull/11450))
* Fixed issue with invalid crash symbolization ([#10450](https://github.com/youtube/cobalt/pull/10450))

### Memory Optimizations & Performance Improvements

* **V8 & Wasm Engine Memory Reductions:**
  * **Smarter Memory Cleanup:** Switched to a more efficient cleanup system (MinorMS GC) to quickly recycle temporary data before it causes bloat. ([#10912](https://github.com/youtube/cobalt/pull/10912))
  * **Reduced Compiler Overhead:** Disabled resource-heavy code compilers (Maglev) that may consume significant memory during runtime. ([#11186](https://github.com/youtube/cobalt/pull/11186))
  * **Immediate Memory Release:** Optimized Wasm memory handling to actively and immediately return unused memory back to the platform operating system. ([#11383](https://github.com/youtube/cobalt/pull/11383))
  * **Optimized Partner Settings:** Turned on memory-saving configurations tailored specifically for 3P devices. ([#11440](https://github.com/youtube/cobalt/pull/11440), [#10912](https://github.com/youtube/cobalt/pull/10912), [#10928](https://github.com/youtube/cobalt/pull/10928))
* **Media Buffer Shedding & 720p Pool Tuning:**
  * **Smarter Memory Cleanup:** Added an automated system that quickly discards video data when no longer needed (e.g. backgrounded). ([#10963](https://github.com/youtube/cobalt/pull/10963))
  * **Ready-to-Use Media Pools:** Preallocated dedicated memory pools for video and audio frames to ensure smoother transitions and reduce the processing delay for media playback. ([#10688](https://github.com/youtube/cobalt/pull/10688))
  * **Configurable Memory Cap for HD:** Set a strict limit on the memory used for demuxing (Media.720pVideoBufferSizeClampMb) when playing videos at 720p resolution or lower, protecting devices with lower memory capacity. ([#10773](https://github.com/youtube/cobalt/pull/10773))
  * **Reduced CPU usage:** Optimized DecodedAudio format switching. ([#11184](https://github.com/youtube/cobalt/pull/11184), [#10724](https://github.com/youtube/cobalt/pull/10724))
* **Cache, Thread Stack & Pipe Memory Optimization:** ptimized ref counting garbage collection, configurable/reduced default thread stack sizes, and added support for Mojo data pipes to only use memory dynamically when data is actively being sent ([#11161](https://github.com/youtube/cobalt/pull/11161), [#10796](https://github.com/youtube/cobalt/pull/10796), [#10823](https://github.com/youtube/cobalt/pull/10823), [#10791](https://github.com/youtube/cobalt/pull/10791))
* **Storage Partitioning & Cache Storage Optimization**: Redirected `CacheStorage` to use the system cache directory (`base::DIR_CACHE` / `kSbSystemPathCacheDirectory`) instead of permanent storage to prevent flash memory exhaustion, and implemented domain-isolated storage partitioning (`kSbSystemPathFilesDirectory`). ([#11458](https://github.com/youtube/cobalt/pull/11458), [#10879](https://github.com/youtube/cobalt/pull/10879), [#10829](https://github.com/youtube/cobalt/pull/10829))
* **Interactive Heap Profiling & Memory Attribution:** Added HTML heap flamegraphs, in-process symbolizers, and integrated PartitionAlloc metrics and context APIs for deeper memory diagnostics. ([#11382](https://github.com/youtube/cobalt/pull/11382), [#11247](https://github.com/youtube/cobalt/pull/11247), [#11037](https://github.com/youtube/cobalt/pull/11037), [#10969](https://github.com/youtube/cobalt/pull/10969), [#10947](https://github.com/youtube/cobalt/pull/10947), [#10850](https://github.com/youtube/cobalt/pull/10850), [#10848](https://github.com/youtube/cobalt/pull/10848), [#11474](https://github.com/youtube/cobalt/pull/11474))
* **Smoother UI Navigation**: Moved CobaltPerformance memory queries to base::ThreadPool to prevent UI thread blocking that may cause screen stutter. ([#11184](https://github.com/youtube/cobalt/pull/11184))

### Testing and Verification

* **NPLB Test Suite:** Added tests for EGL 1.5, POSIX (`unlinkat`, `openat`, `fstatat`) and updated vertical video tests ([#11297](https://github.com/youtube/cobalt/pull/11297), [#10945](https://github.com/youtube/cobalt/pull/10945), [#11101](https://github.com/youtube/cobalt/pull/11101), [#10897](https://github.com/youtube/cobalt/pull/10897), [#10886](https://github.com/youtube/cobalt/pull/10886), [#10913](https://github.com/youtube/cobalt/pull/10913))

## Starboard Changes

*NOTE: The below changes represent the delta between the RC1 and RC2 releases.*

See comprehensive list of changes in [starboard/CHANGELOG.md](https://github.com/youtube/cobalt/blob/27.lts.2/starboard/CHANGELOG.md) and baseline [release notes for Cobalt 27 RC](https://developers.google.com/youtube/cobalt/docs/releases/27.LTS.1) on cobalt.dev.

### New & Updated Starboard Extensions

* **\[Required\] New Hang Detection and Reporting** \- **CobaltExtensionCrashHandlerApi**
  * Cobalt is now able to detect hangs to better diagnose in-field platform issues
  * The platform should continue to simply wire up the provided, shared implementation of the extension at:
    * [`starboard/shared/starboard/crash_handler.h`](https://github.com/youtube/cobalt/blob/27.lts.2/starboard/shared/starboard/crash_handler.h)
    * [`starboard/shared/starboard/crash_handler.cc`](https://github.com/youtube/cobalt/blob/27.lts.2/starboard/shared/starboard/crash_handler.cc)

* **\[Required\] New StarboardExtensionNativeStabilityApi**
  * Enables YouTube to more reliably log stability events like crashes and hangs
  * No custom implementation; the platform must just wire up the provided, shared implementation of the extension at:
    * [`starboard/shared/starboard/native_stability.h`](https://github.com/youtube/cobalt/blob/27.lts.2/starboard/shared/starboard/native_stability.h)
    * [`starboard/shared/starboard/native_stability.cc`](https://github.com/youtube/cobalt/blob/27.lts.2/starboard/shared/starboard/native_stability.cc)
