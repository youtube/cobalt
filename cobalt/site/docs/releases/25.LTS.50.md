# Cobalt 25.LTS.50

## Cobalt Changes

The Cobalt team has published updates to the Cobalt `25.lts.stable` branch with tag [25.lts.50](https://github.com/youtube/cobalt/tree/25.lts.50) (25.lts.50.1035044).

The Evergreen binaries are available on GitHub ([5.50.2](https://github.com/youtube/cobalt/releases/tag/25.lts.50))

### Critical Bug Fixes

* **V8 & JavaScript:** Fixed V8 compilation cache handling to retain compiled JavaScript scripts despite rejected cache entries, avoiding unnecessary script recompilation and cleaning up rejected cache items. ([#10314](https://github.com/youtube/cobalt/pull/10314))
* **Evergreen Updater:** Fixed an `std::out_of_range` exception and process crash in `UpdateEngine::Cancel`. ([#10900](https://github.com/youtube/cobalt/pull/10900))
* **Network & DevTools:** Updated `SbSocketIsIpv6Supported()` to dynamically probe IPv6 support with temporary socket binding and fall back to IPv4 for DevTools server binding if IPv6 is unsupported. ([#11104](https://github.com/youtube/cobalt/pull/11104))

### Android

* Fixed thread cleanup on AOSP by using the TLS value provided in the destructor to detach the JNI environment (`SbThreadDetach`) from the current thread. ([#10254](https://github.com/youtube/cobalt/pull/10254))

### Security Fixes

* **SSL Root Certificates:** Loaded SSL root certificates directly into memory at startup into the BoringSSL trust store guarding against crashes ([#11539](https://github.com/youtube/cobalt/pull/11539))
