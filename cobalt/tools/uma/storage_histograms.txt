# Cobalt storage, cache, and disk I/O UMA histograms.
#
# Usage from the repository root:
#   vpython3 cobalt/tools/uma/pull_uma_histogram_set_via_cdp.py \
#     --histogram-file cobalt/tools/uma/storage_histograms.txt
#
# Note: CDP Browser.getHistograms performs a substring match on each query line.
# Lines starting with '#' are ignored. Histograms are organized by priority tier:
#   - P0: Primary causal mechanism metrics (footprint, quotas, cache hits, commits)
#   - P1: Subsystem latency, throughput, and commit delay metrics
#   - P2: Startup, thread congestion, data integrity, and migration guardrails
# Superseded or confounded histograms are documented as comments at the bottom.

# Dropped / Not Queried (Comments Only)

# Cobalt.Storage.Cookie.CommitDurationPerOperation
#   Divides transaction duration by ops.size(). Use Cobalt.Storage.Cookie.CommitDuration.
# Cobalt.Storage.Exit.LocalStorageFlushSchedulingDuration
#   Measures CPU time to post the async Mojo flush message, not disk write completion.
#   Use Cobalt.Storage.LocalStorage.CommitDuration instead.
# LevelDBWrapper.CommitDelay
#   Never recorded in Cobalt because --enable-aggressive-domstorage-flushing
#   returns 1s before the histogram macro in StorageAreaImpl::ComputeCommitDelay().
#   Use DOMStorage.CommitMeasuredDelay instead.
# HttpCache.AccessToDone2
#   Includes live origin download time on cache misses. Use AccessToDone2.Used
#   and HttpCache.BeforeSend instead.
# Cookie.CookieJarSize
#   Counts cookies in RAM; use Cobalt.Storage.UserData.StartupTotalSizeKB for disk.
