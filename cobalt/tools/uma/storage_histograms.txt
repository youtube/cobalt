# Cobalt storage, cache, and disk I/O UMA histograms.
#
# Usage from the repository root:
#   vpython3 cobalt/tools/uma/pull_uma_histogram_set_via_cdp.py \
#     --histogram-file cobalt/tools/uma/storage_histograms.txt
#
# Note: CDP Browser.getHistograms performs a substring match on each query line.
# Lines starting with '#' are ignored. The lab A/B harness (experiment/) keeps
# only names that equal a line or extend it after a '.', and orders report rows
# by tier (P0 -> P1 -> P2) and first matching line.
#
# Histograms are organized into three priority tiers by user-experience impact:
#   - P0 (Core, 11 metrics): Direct predictors of user-visible startup delay,
#     foreground hang/ANR risk, persistent sign-in data loss, or partner
#     certification storage budgets (1 MiB UserData, 24 MiB DirCache).
#     Availability tags:
#       [lab]   emits in a standard short on-device run ([lab*] = conditional on
#               profile state or --exit-flush; [lab >=60s] = 1-min window).
#       [fleet] queried in weekly fleet telemetry ([fleet 8.04+] = added in
#               PR #13979; [rasta] = exported to Rasta / raw telemetry).
#       [vega]  Phase-2 Vega/Perfgate regression-gate subset (b/586376647).
#   - P1 (Mechanism): Subsystem metrics explaining why a P0 metric moved (DB
#     loads/commits, write volume, store sizes, cache hit/eviction/index states,
#     unused-store SQL/writes, shader preload, and recovery/migration outcomes).
#   - P2 (Context): Slicing covariates (OS page cache, startup milestones),
#     thread congestion, RAM/exit guardrails, PMA health, and per-op details.
# Superseded or always-zero histograms are documented as comments at the bottom.

# Dropped / Not Queried (Comments Only)

# Cobalt.Storage.Cookie.CommitDurationPerOperation
#   Divides transaction duration by ops.size(). Use
#   Cobalt.Storage.Cookie.CommitDuration.
# Cobalt.Storage.Exit.LocalStorageFlushSchedulingDuration
#   Measures CPU time to post the async Mojo flush message, not disk write
#   completion. Use Cobalt.Storage.LocalStorage.CommitDuration instead.
# LevelDBWrapper.CommitDelay
#   Never recorded in Cobalt because --enable-aggressive-domstorage-flushing
#   returns 1s before the histogram macro in
#   StorageAreaImpl::ComputeCommitDelay(). Use DOMStorage.CommitMeasuredDelay.
# HttpCache.AccessToDone2
#   Includes live origin download time on cache misses. Use AccessToDone2.Used
#   and HttpCache.BeforeSend instead.
# Cookie.CookieJarSize
#   Counts cookies in RAM; use Cobalt.Storage.UserData.StartupTotalSizeKB2 for
#   disk.
# Memory.Experimental.Browser2.Small.LevelDatabase
# Memory.Experimental.Browser2.Small.Sqlite
#   UmaHistogramMemoryKB min=1000 KB clips 100% of fleet samples into bucket 0.
# Privacy.DIPS.DatabaseSize
#   Stats only the main DIPS file (4 KB), missing DIPS-wal (483-692 KB). Use
#   Cobalt.Storage.UserData.StartupTotalSizeKB2 for the directory total.
