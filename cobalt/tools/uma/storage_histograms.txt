# Cobalt storage and disk I/O UMA histograms.

# Usage from the repository root:
#   vpython3 cobalt/tools/uma/pull_uma_histogram_set_via_cdp.py \
#     --histogram-file cobalt/tools/uma/storage_histograms.txt

# Lines starting with '#' are ignored. Histograms are grouped by the question
# they answer. Error-path histograms (section 5) only appear after an error.
# Histograms that are superseded, misleading or never recorded are listed at
# the end as comments, so they are not queried.
