# Critic Review Enablement
Custom critics need `name`, `description`, and `tags` or `codeowner_teams`.
```markdown
## Source Code Control Policy
- [ ] **Codeowners Review**: Required via `.github/CODEOWNERS` critics.
- [ ] **KISSY Review**: Required via `kissy-reviewer`.
- [ ] **Style Guide Review**: Required via `styleguide-reviewer`.
```
