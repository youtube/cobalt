# Cobalt 25.LTS.60

The Cobalt team has published updates to the Cobalt `25.lts.stable` branch with tag [25.lts.60](https://github.com/youtube/cobalt/tree/25.lts.60) (25.lts.60.1035053).

The Evergreen binaries are available on GitHub ([5.60.2](https://github.com/youtube/cobalt/releases/tag/25.lts.60)).

Considering the security fix for compromised TLS certificates and the QUIC download recovery fix included in this release, the Cobalt team **strongly recommends** that partners running Cobalt `25.lts.stable` on existing devices update to `25.lts.60` as soon as possible.

## Cobalt Changes

### Critical Bug Fixes

* **QUIC Download Recovery:** Fixed stalled QUIC network downloads when resuming traffic after playback or background pauses. ([#13720](https://github.com/youtube/cobalt/pull/13720))

### Security Fixes

* **SSL Certificate Verification:** Blocked compromised intermediate TLS certificates during SSL certificate chain validation (CVE-2026-114406). ([#13812](https://github.com/youtube/cobalt/pull/13812))

### Updates/Improvements

* **Docker Build Environment:** Updated the Linux base Docker image to use archived Debian 11 snapshot mirrors. ([#12714](https://github.com/youtube/cobalt/pull/12714))
