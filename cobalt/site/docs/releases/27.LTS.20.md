# Cobalt 27.LTS.20

The Cobalt team has published **Cobalt 27.LTS.20** including **Starboard API version 18** to the [`27.lts`](https://github.com/youtube/cobalt/tree/27.lts) branch with tag [`27.lts.20`](https://github.com/youtube/cobalt/tree/27.lts.20) (`27.lts.20.1041436`).

* [cobalt/CHANGELOG.md](https://github.com/youtube/cobalt/blob/27.lts.20/cobalt/CHANGELOG.md)
* [starboard/CHANGELOG.md](https://github.com/youtube/cobalt/blob/27.lts.20/starboard/CHANGELOG.md)

Corresponding Evergreen binaries (`7.20.2`) are available on [GitHub at the 27.lts.20 Release tag](https://github.com/youtube/cobalt/releases/tag/27.lts.20).

This is a **Stable** release for 2027 YouTube device certification. Considering the critical Evergreen upgrade fix and playback stability improvements included in this release, the Cobalt team **strongly recommends** that partners upgrading from Cobalt 25 (or earlier) or currently on `27.lts.10` migrate to `27.lts.20` as soon as possible.

---

## Cobalt Changes

### Bug Fixes

* **[CRITICAL] Evergreen Upgrade Migration:** Fixed a slot-migration issue when upgrading from Cobalt 25 to Cobalt 27 that blocked future Evergreen updates. ([#13471](https://github.com/youtube/cobalt/pull/13471))
* **Evergreen Updater:** Hardened update package verification and fixed local LTS builds defaulting to version 1.0.0. ([#13462](https://github.com/youtube/cobalt/pull/13462), [#13123](https://github.com/youtube/cobalt/pull/13123), [#12909](https://github.com/youtube/cobalt/pull/12909))
* **Video Playback & Seeking:** Fixed frozen progress bars on backward seeks, black screens on resume, and multi-video layer ordering. ([#13721](https://github.com/youtube/cobalt/pull/13721), [#13360](https://github.com/youtube/cobalt/pull/13360), [#13623](https://github.com/youtube/cobalt/pull/13623))
* **Media Pipeline Stability:** Resolved media startup hangs, idle GPU texture crashes, and unprotected DRM video texture handling. ([#13066](https://github.com/youtube/cobalt/pull/13066), [#13114](https://github.com/youtube/cobalt/pull/13114), [#13116](https://github.com/youtube/cobalt/pull/13116))
* **QUIC Download Recovery:** Fixed stalled QUIC network downloads when resuming traffic after playback or background pauses. ([#13479](https://github.com/youtube/cobalt/pull/13479))
* **Native Display Resolution:** Honored non-1080p native window sizes (such as 720p) instead of forcing 1920x1080. ([#13352](https://github.com/youtube/cobalt/pull/13352))
* **Startup Stability:** Fixed 64-bit window pointer crashes on Linux/Ozone and resolved timezone deadlocks during launch. ([#12932](https://github.com/youtube/cobalt/pull/12932), [#13142](https://github.com/youtube/cobalt/pull/13142), [#13069](https://github.com/youtube/cobalt/pull/13069))
* **CJK Font Rendering:** Restored bold text styling for CJK and other single-weight fallback fonts. ([#13714](https://github.com/youtube/cobalt/pull/13714))
* **Video Splash Screen:** Timed splash screens from the first rendered video frame so startup animations are not cut short. ([#13464](https://github.com/youtube/cobalt/pull/13464))
* **Security Fixes:** Blocked compromised intermediate TLS certificates during SSL verification (CVE-2026-114406) and patched a Brotli stream-decoding vulnerability (CVE-2026-111497). ([#13760](https://github.com/youtube/cobalt/pull/13760), [#13940](https://github.com/youtube/cobalt/pull/13940))

### Memory Reductions & Performance Improvements

* **Warm-Launch Font Caching:** Added experiment-controlled background font caching to reduce warm-launch memory usage without blocking startup threads. ([#13165](https://github.com/youtube/cobalt/pull/13165))
* **3P Rendering & IPC:** Enabled faster in-process image rendering and dynamic IPC buffer sizing by default on 3P devices. ([#12996](https://github.com/youtube/cobalt/pull/12996))
* **Zero-Copy Media Streaming:** Reduced playback memory usage on 3P devices with zero-copy MP4/WebM parsing and external media buffer pools. ([#13617](https://github.com/youtube/cobalt/pull/13617), [#13521](https://github.com/youtube/cobalt/pull/13521), [#12846](https://github.com/youtube/cobalt/pull/12846), [#13015](https://github.com/youtube/cobalt/pull/13015), [#13017](https://github.com/youtube/cobalt/pull/13017), [#12991](https://github.com/youtube/cobalt/pull/12991))
* **Disk Footprint Caps:** Capped Service Worker (6 MiB) and Wasm (1 MiB) caches and disabled GPU shader disk caching. ([#12441](https://github.com/youtube/cobalt/pull/12441), [#13670](https://github.com/youtube/cobalt/pull/13670), [#13044](https://github.com/youtube/cobalt/pull/13044))
* **Startup Responsiveness:** Deferred V8 code-cache disk writes to idle time so launch work never blocks UI rendering. ([#13167](https://github.com/youtube/cobalt/pull/13167))

### AOSP & RDK

* **AOSP:**
  * Restored support for Android 7.0+ (API 24+) devices and fixed crashes when backgrounded during startup. ([#13108](https://github.com/youtube/cobalt/pull/13108), [#13245](https://github.com/youtube/cobalt/pull/13245))
  * Disabled QUIC by default on AOSP and enabled network error dialogs and video surface bounds. ([#13354](https://github.com/youtube/cobalt/pull/13354), [#13482](https://github.com/youtube/cobalt/pull/13482), [#13273](https://github.com/youtube/cobalt/pull/13273), [#13282](https://github.com/youtube/cobalt/pull/13282))
  * Disabled debug and profile flags on official AOSP release builds to avoid ART overhead and partner security-check failures. ([#13553](https://github.com/youtube/cobalt/pull/13553))
  * Improved video decoder input backpressure handling and added DRM session-close callbacks for smoother playback. ([#13118](https://github.com/youtube/cobalt/pull/13118), [#13178](https://github.com/youtube/cobalt/pull/13178))
  * Enabled crash/stability reporting, Text-to-Speech accessibility, device model reporting, and Java exception stack traces. ([#12916](https://github.com/youtube/cobalt/pull/12916), [#12975](https://github.com/youtube/cobalt/pull/12975), [#13186](https://github.com/youtube/cobalt/pull/13186), [#13110](https://github.com/youtube/cobalt/pull/13110), [#13561](https://github.com/youtube/cobalt/pull/13561))
  * Added documentation for running NPLB certification tests using Android Debug Bridge (adb) alone. ([#13542](https://github.com/youtube/cobalt/pull/13542))
* **RDK:**
  * Added pre-app recommendation service support and improved portrait video resolution detection. ([#12872](https://github.com/youtube/cobalt/pull/12872), [#13527](https://github.com/youtube/cobalt/pull/13527))

## Starboard Changes

* **Low Memory Kill Diagnostics:** Updated the LowMemoryKill extension (v2) with detailed OS out-of-memory diagnostics while keeping v1 backward compatibility. ([#13593](https://github.com/youtube/cobalt/pull/13593))
* **Widevine DRM Security:** Added bounds checks on CDM key IDs to prevent potential buffer overflows. ([#13534](https://github.com/youtube/cobalt/pull/13534))
* **Audio Playback:** Handled early audio format switches before playback starts and added support to skip unnecessary audio resampling. ([#13481](https://github.com/youtube/cobalt/pull/13481), [#13467](https://github.com/youtube/cobalt/pull/13467))
* **System & POSIX:** Standardized SSL certificate paths, added OS random-byte generation support, and improved DNS, timezone, and ARM64 crash unwinding. ([#13068](https://github.com/youtube/cobalt/pull/13068), [#13351](https://github.com/youtube/cobalt/pull/13351), [#13246](https://github.com/youtube/cobalt/pull/13246), [#13052](https://github.com/youtube/cobalt/pull/13052), [#12966](https://github.com/youtube/cobalt/pull/12966), [#12977](https://github.com/youtube/cobalt/pull/12977))
* **Crash Symbolizer Tooling:** Unified log symbolization across Cobalt stack dumps, RDK syslogs, Android logcat, and GDB outputs. ([#12585](https://github.com/youtube/cobalt/pull/12585))
* **NPLB Graphics & Media Tests:** Made AV1 HDR optional for non-HDR 4K TVs. ([#13347](https://github.com/youtube/cobalt/pull/13347))
* **NPLB POSIX & Audio Tests:** Fixed audio buffer startup timeouts and POSIX memory-alignment, hard-link, and process-priority false failures. ([#13271](https://github.com/youtube/cobalt/pull/13271), [#13148](https://github.com/youtube/cobalt/pull/13148), [#13270](https://github.com/youtube/cobalt/pull/13270), [#13105](https://github.com/youtube/cobalt/pull/13105))
